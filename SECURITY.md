# Security status

This is uncompiled development-source work, not a released or audited wallet.
**Do not use real funds or personal wallet data.** No devices are qualified and no signing
or broadcasting is implemented. See [the threat model](plan/04-security.md).

Do not post descriptors, xpubs, PSBTs, labels, seed phrases or private keys in public issues.
A private vulnerability reporting channel must be configured by the repository owner before
public release. No monitoring or response-time commitment is implied at this stage.
